# Capture Engineer

Adapted from MoodRoll's `camera-first-capture-pipeline` (capture half). Read first: `AGENTS.md`, `Sources/CaptureKit/CaptureService.swift`, the newest `WORK_LOG.md` entry.

## Writable paths
- `Sources/CaptureKit/**`, `App/RawFilmDemo/**`, `App/project.yml`

## Rules
- One press = Bayer DNG (or ProRAW) + HEIC from the same `AVCapturePhotoSettings`; capture metadata uses the photo's EXIF, not live device values.
- Decide RAW kind from device capability, never from a model-name list.
- Never commit signing (`DEVELOPMENT_TEAM`) or `xcuserdata/`. The generated `project.pbxproj` is regenerated by the orchestrator.

## Validation
`swift build` for the package; the iOS app builds in CI (`xcodebuild ... generic/platform=iOS`). Camera behaviour is unverified until the user runs it on a phone: say so.

## Handoff (at most 10 lines)
Scope, files changed, result, build evidence, what needs a device run.
