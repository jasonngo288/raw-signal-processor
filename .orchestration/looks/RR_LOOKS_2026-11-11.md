## Chuẩn: why character and a cut, not cut alone
- Before, Chuẩn (brightTravel @ 0.55) measured image ΔE 1.2 vs base and chart ΔE 1.22. In the renders it could not be
  told from base.
- cleanLab @ 0.85: image ΔE mean 1.70 (0.9–2.7), chart 1.46 vs base.
- On the renders it reads as a clean lab scan:
  - whites hold detail instead of clipping (IMG_1901 clip 45 % → 0 %);
  - slightly deeper reds and blues; neutral greys;
  - grain at ISO 400.
- It stays subtle by design: that is the point of a lab-neutral stock. If the user still finds it too close to base,
  the next step is intensity 1.0, not more colour.

## Light leak spec (for Lá Phong 100; NOT built. A raw-core engineer builds it as a plugin, AGENTS rule 10)
- **What it is:** light that got past the camera's door seal, or that fogged the start and end of the roll.
- **Shape:**
  - One soft, large glow that enters from a frame edge, along the long axis (where the door gap and sprockets are).
  - Elliptical. Its core sits 0–10 % outside the frame edge. It falls off in a Gaussian to about 20–40 % of the
    frame width.
  - Optional faint vertical band (streak), 5–12 % wide, from the same edge.
  - No hard edges and no geometric shapes. It is blurred in linear light.
- **Colour:**
  - Red-orange core (linear ≈ [1.0, 0.30, 0.06]; OKLCh hue ≈ 35–45°), shading to amber/yellow at the outer falloff
    (hue ≈ 70°).
  - Never magenta, pink or neon.
  - Blended as screen or soft-add in linear light, so it lifts shadows more than highlights. Capped so the output
    stays ≤ 0.99 encoded (no new clip).
- **Placement:**
  - Random edge (left or right in landscape), random position along it.
  - Never centred. Avoid the central third.
  - Attenuate × 0.4 inside the Vision person mask, so faces never sit under the core.
- **Per-frame variation across a roll** (deterministic: seed = roll id + frame index, logged in the recipe):

  | frames | chance | strength |
  |---|---|---|
  | 1–2 | always (fogged roll start) | strong, 0.6–0.9 |
  | 3 | 50 % | 0.3–0.5 |
  | middle of the roll | ~12 % of frames | faint, 0.15–0.35 |
  | last frame | 60 % | medium |

  - Per frame, jitter hue ±8°, size ±30 % and edge position.
  - Never two strong leaks in a row mid-roll.
- **Strength:**
  - Default peak add ≈ +0.25 linear at the core, at strength 1.
  - Global amount 0.35 for Lá Phong. The user can turn it off.
  - Removable with `plugins = []`; listed in `recipe.plugins` and the ROADMAP EXTRAS table.
  - The recipe logs seed, edge, position, strength and hue per frame.
